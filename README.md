# Anna's Garden Hotel — Tbilisi

Production website for **Anna's Garden Hotel**, 10 Shalva Mshvelidze Street, Tbilisi.

**Release:** v1.0.0 · August 2026

## Direction
- Bright, architectural editorial design adapted from the ADAM hotel system
- Premium static hero using a retouched real room photograph
- EN / RU / KA language support with persisted preference
- Editorial Rooms, Hotel, Gallery, Amenities, Guest Rating and Location sections
- Booking drawer linked to Booking.com live availability
- Responsive desktop / tablet / mobile layout
- Real hotel photography curated into a lightweight WebP atlas

## Public listing facts used
Public Booking.com and hotel-listing information checked in August 2026, including the address, room types, amenities, airport distance and a Booking.com rating snapshot. Review scores can change over time and should be rechecked before a long-term public launch.

## Stack
- Next.js 16.1.6
- React 19
- TypeScript
- Custom responsive CSS
- Vercel-ready
