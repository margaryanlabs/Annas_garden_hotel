# Anna's Garden Hotel — website

Production website for Anna's Garden Hotel in Tbilisi.

## Stack

- Next.js
- TypeScript
- Responsive editorial UI
- EN / RU / KA
- Booking.com availability handoff

## Media

The site now uses individual high-resolution WebP assets for the hero, rooms and gallery rather than a compressed sprite atlas.
